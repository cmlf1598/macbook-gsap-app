
# App setup -------------------------

1. npm create vite@latest ./
2. Remove app.jsx, app.css, all assets and clean index.css
3. Add App.jsx
4. Install Tailwind (npm install tailwindcss @tailwindcss/vite)
5. In vite.config.js add tailwindcss
